    Main parts

    Generates or updates data/bt/main_parts.csv from the Rebrickable parts and the Brick Tools part categories. Parts of hidden categories and child parts are excluded; existing star ratings are kept.

    Part color URLs

    Generates or updates data/bt/part_color_url.csv from the Rebrickable inventory parts. Only the first inventory row of each part/color pair with an image URL is kept; rows without an image URL are skipped.
